# One-Take Classroom QA — PHYSICS COOLNUT CENTER

เป้าหมาย: ใช้งานส่งผลงานกลุ่มในคาบสอนฟิสิกส์และฉายผลงานนักเรียนด้วย Touchscreen โดยไม่ทำให้กระบวนการสอนสะดุด

## Gate A — เนื้อหาและปุ่ม

- [ ] ครูสร้าง/แก้ปุ่มลิงก์: URL PhET/Quiz ภายนอก ใช้งานได้จากเครื่องนักเรียนจริง
- [ ] ครูสร้างปุ่มส่งงาน พร้อมชื่อกิจกรรม ห้องเรียน และ "สิ่งที่ต้องส่ง" ถูกต้อง
- [ ] หน้าแรกแยกส่วนลิงก์กับส่วนส่งงานอย่างชัดเจน
- [ ] โหมดนักเรียนไม่สามารถสร้าง/แก้ปุ่มของครู

## Gate B — ผลงานและข้อมูลสมาชิก

- [ ] 8 กลุ่มสร้างการ์ดได้โดยไม่ชนหมายเลขกลุ่ม
- [ ] ชื่อและนามสกุล ชั้น และเลขที่ของสมาชิกครบถ้วน ตรวจเลขที่ซ้ำได้
- [ ] ภาพหมู่และใบงาน A4 2 หน้าอ่านชัด (หน้าที่ 1 มี FBD วาดบนภาพคาน)
- [ ] หากเปิดการ์ดกลุ่ม เห็นผู้ส่ง เลขกลุ่ม รายละเอียดสมาชิกและใบงานตามลำดับ
- [ ] อัปโหลดแล้วมีการตอบรับจาก Server จริง; Retry แล้วไม่เกิดข้อมูลเสีย/ภาพสูญหาย
- [ ] ภาพและข้อมูลส่วนบุคคลไม่เปิดผ่านลิงก์สาธารณะโดยไม่ตั้งใจ

## Gate C — สไลด์และคาบเรียน

- [ ] ครูเลือกการ์ดกลุ่มที่จะนำเสนอจากหน้ากิจกรรม
- [ ] นักเรียนกดก่อนหน้า/ถัดไปเองบนจอ Touchscreen ได้สะดวก
- [ ] Fullscreen, Zoom, Swipe ใช้ได้จริงพร้อมภาพใบงานขนาดเต็ม
- [ ] ใช้เวลาส่งภาพและเปลี่ยนสไลด์ไม่เบียดเวลาอภิปราย/Exit Ticket
- [ ] ถ้าเว็บ/อินเทอร์เน็ตมีปัญหา มีชุดภาพออฟไลน์หรือกระดาษเพื่อฉายได้ทันที

## Gate D — หลักฐานและรายงาน

- [ ] Feedback จากกลุ่มอื่นและการแก้ไข Revision บันทึกพร้อมเวลา
- [ ] Export Metadata มีข้อมูลสมาชิก การส่งงาน คำตอบ Quiz (ถ้าเปิด) และสถิติอย่างถูกต้อง
- [ ] ข้อมูลที่ส่งออกมีฐานข้อมูลจริง ไม่อ้างว่า DEMO คือผลงานนักเรียนจริง
- [ ] ทดสอบทั้งหมดกับ Google Sheets/Drive, Chromebook และ Touchscreen ก่อนถ่ายคลิปครั้งเดียว
