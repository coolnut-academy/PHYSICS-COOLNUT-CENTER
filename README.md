# PHYSICS COOLNUT CENTER

**Physics Learning Hub · Resource Links · Group Submissions · Touchscreen Presentation**

> **v1.0 prototype — DEMO ผ่านการตรวจ Syntax และ Mock API; LIVE ยังไม่ผ่านการยืนยันกับ Google Services**
> พัฒนาต่อยอดจากซอร์สต้นแบบ `Hongson_Classfolio_Group_Presentation_v0.9.zip` ในบทสนทนานี้ ไม่ใช่การดัดแปลง Source Code ของ Hongson Student Innovators เดิมโดยตรง เพราะแหล่งข้อมูลที่ได้รับจากระบบนั้นคือ `README.md` เท่านั้น

## แนวคิดหลัก

PHYSICS COOLNUT CENTER เป็นศูนย์รวมกิจกรรมฟิสิกส์ที่ครูสร้าง **ปุ่ม/การ์ดกิจกรรมได้สองประเภท** แยกชัดเจนบนหน้าแรก:

| ประเภทปุ่ม | ครูตั้งค่า | นักเรียนทำอะไร |
|---|---|---|
| **ลิงก์** (Learning Link) | ชื่อปุ่ม หมวด ชั้น คำอธิบาย URL | กดเพื่อเปิดเว็บภายนอก เช่น PhET, YouTube, Google Forms/Quiz ในแท็บใหม่ |
| **ส่งงาน** (Group Submission) | ชื่อกิจกรรม รหัสเข้าร่วม คำสั่ง และ “สิ่งที่ต้องส่ง” | เข้ากิจกรรมด้วยรหัส สร้างการ์ดกลุ่ม กรอกชื่อ–นามสกุล ชั้น และเลขที่ของสมาชิก ถ่ายภาพหมู่และส่งใบงาน |

ภายใน **ปุ่มส่งงาน** นักเรียนแต่ละกลุ่มมีการ์ดของตัวเองพร้อม:
- ชื่อกลุ่ม / หมายเลขกลุ่ม และภาพหมู่หน้าปก (Cover)
- รายชื่อสมาชิกแบบแยกช่อง **ชื่อ, นามสกุล, ชั้น, เลขที่** (1–8 คน)
- ใบงาน A4 หน้า 1 (Predict/FBD) และหน้า 2 (Observe/Explain)
- คลิกดูรายละเอียดกลุ่มแล้วเห็นรายชื่อสมาชิกและไฟล์ที่ส่ง
- โหมด **Slide Show**: ภาพหมู่ → ใบงาน 1 → ใบงาน 2, ปุ่มลูกศรใหญ่บน Touchscreen, Swipe, Fullscreen, Zoom, ปุ่ม Esc
- Peer Feedback และ Revision บันทึกเหตุผลการปรับความเข้าใจ
- Quiz ภายนอกสร้างเป็นปุ่ม **ลิงก์** แยกต่างหากได้เลย (ไม่มี Quiz ซ้อนภายในเว็บส่งงาน)
- ครู Export JSON รายการส่งงาน / รายชื่อสมาชิก / Feedback (ไม่รวมไฟล์ภาพ)

## ใช้งานโหมด DEMO

เปิดโฟลเดอร์นี้ใน VS Code แล้วใช้ Live Server หรือรัน:

```bash
python -m http.server 4173
# เปิด http://localhost:4173
```

1. เปิดหน้าแรก มีปุ่ม **เรียนรู้** (ลิงก์ตัวอย่าง) แยกจาก **ส่งงาน**
2. คลิก **ส่งงาน · สมดุลต่อการหมุน** ด้วยรหัสตัวอย่าง `TL2569`
3. เลือกดูผลงานกลุ่ม หรือกด **ฉาย** เพื่อนำเสนอภาพปกและใบงานบน Touchscreen
4. คลิก **สร้างการ์ดกลุ่ม** กรอกรายชื่อสมาชิกทีละคน และอัปโหลดภาพทดลอง
5. เข้า **โหมดครู** (DEMO ไม่ใช้รหัสจริง), กด **สร้างปุ่มกิจกรรม** → เลือก *ลิงก์* หรือ *ส่งงาน*, ทดลองสร้างและแก้ไขปุ่ม
6. ใช้ปุ่ม **ลิงก์** สำหรับ Quiz ภายนอก (เช่น Google Forms, Kahoot, Quizizz) แยกจากกิจกรรมส่งงาน

> DEMO มี **4 ปุ่มตัวอย่าง** (2 ลิงก์, 2 ส่งงาน) และกลุ่มตัวอย่าง 3 กลุ่ม ข้อมูลอยู่เฉพาะเบราว์เซอร์ใน IndexedDB ไม่ซิงก์ระหว่างอุปกรณ์ ผลงานตัวอย่างไม่ใช่หลักฐานการสอนจริง

## สถาปัตยกรรม

- Frontend: HTML5/CSS3/Vanilla JavaScript ES Modules — รันบน GitHub Pages ได้ (`index.html` อยู่ root)
- Backend LIVE: Google Apps Script Web App (`doPost` JSON + RPC Bridge)
- Database: Google Sheets (`Topics`, `Groups`, `Feedback`, `AdminLog`)
- Media: Google Drive แบบ Private; API ยืนยันสิทธิ์ก่อนคืนรูป (ห้ามใช้ลิงก์ Anyone With Link)
- Auth: ครูใช้ Password Hash + Session Token; นักเรียนใช้ Access Code ของกิจกรรมและ Group Edit Code แยกกัน
- Photo Upload: บีบอัดภาพบน Client ก่อนส่ง แต่ต้องทดสอบกับ Wi-Fi และอุปกรณ์จริงทุกครั้ง

ดู [`docs/SETUP_LIVE.md`](docs/SETUP_LIVE.md) สำหรับขั้นตอน deploy และ [`docs/QA_ONE_TAKE.md`](docs/QA_ONE_TAKE.md) สำหรับรายการตรวจรับก่อนวันถ่ายคลิป

## ความเข้ากันได้กับข้อมูลเดิม

- หัวข้อที่ไม่มี `type` จะถูกตีความเป็นประเภท **ส่งงาน** โดยอัตโนมัติ
- ข้อมูล Groups เดิมที่มีแต่ช่องข้อความ `members` ยังแสดงได้; เมื่อแก้ไขงานจะขอให้กรอกข้อมูลสมาชิกแบบใหม่ครบ
- Backend เพิ่มคอลัมน์ท้ายตารางเดิม (`type`, `targetUrl`, `requirements`, `membersJSON`) โดยฟังก์ชัน `setupPhysicsCoolnut()`; **สำรอง Spreadsheet และ Drive ก่อน migration**
- ไม่ได้ย้ายไฟล์จริงจากระบบ Hongson Student Innovators เดิม เพราะไม่มี Source Database/Drive ที่เชื่อมอยู่ในบทสนทนานี้

## ความปลอดภัยและข้อจำกัด

- **ภาพเด็กและชื่อ–นามสกุล/ชั้น/เลขที่ เป็นข้อมูลส่วนบุคคล**: ต้องมีฐานการใช้งานและการอนุญาตตามนโยบายโรงเรียน ห้ามเก็บลง public repo หรือเผยแพร่การ์ดสู่สาธารณะ
- รหัสเข้าหัวข้อสำหรับนักเรียนที่ใช้ร่วมกันไม่ได้เทียบเท่าระบบ SSO; ผู้มีรหัสสามารถดูรายชื่อและภาพของกลุ่มภายในกิจกรรมนั้นได้ พิจารณาลดการแสดงรายชื่อหากนโยบายโรงเรียนกำหนด
- ยังไม่ได้ทดสอบ UI ผ่านเบราว์เซอร์อัตโนมัติในสภาพแวดล้อมนี้ และยังไม่ได้ทดสอบ LIVE Google Sheets/Drive
- โหมด DEMO ไม่มีการยืนยันตัวตนของครูจริง ห้ามใช้เก็บข้อมูลนักเรียนจริง
- ระบบไม่รับประกันการอัปโหลดพร้อมกันทั้ง 8 กลุ่ม: ต้องทดสอบก่อนวันสอนจริง (รวมการถ่ายภาพ/แสดงภาพ/ส่งออกหลักฐาน)
- การบันทึกภาพลง Drive อาจสำเร็จแต่การบันทึกข้อมูลลง Sheets ล้มเหลวระหว่างทาง: อย่ากดส่งซ้ำโดยไม่ตรวจข้อมูลก่อน
